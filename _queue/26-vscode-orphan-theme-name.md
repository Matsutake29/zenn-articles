Word や Excel を VS Code 内で開ける拡張（Office Viewer）を入れました。

入れた直後、**エディタ全体の配色が変わりました。** テーマなんて触っていないのに。

原因を特定してみたら、少し面白い話でした。

## 設定には、ずっと前からこう書いてあった

`settings.json` を見ると、この1行があります。

```json
"workbench.colorTheme": "One Dark Modern Classic",
```

自分で書いた覚えはあります。昔このテーマが気に入って設定しました。

ところが、インストール済みの拡張を全部調べたら、**カラーテーマ拡張は1つも入っていませんでした。**

テーマを提供していた拡張のほうが、いつの間にか消えていたようです。アンインストールしたのか、拡張自体が非公開になったのかは分かりません。

## ここが今回いちばんの学び

**VS Codeは、指定されたテーマが見つからないとき、エラーも警告も出しません。**

黙ってデフォルト（Dark Modern）で表示します。

だから「設定に書いてある名前」と「実際に見えている配色」が、長期間ズレたままでした。
デフォルトのテーマも普通に見やすいので、困ることもなく、気づきようもない。

そこへ Office Viewer が入ってきました。

この拡張、看板のOfficeビューア機能とは別に、**カラーテーマを2つ同梱しています。**
名前が "One Dark Modern" と "One Dark Modern Classic"。

設定に書いてあった迷子の名前が、ここで実体化しました。だから突然切り替わったわけです。

## どう特定したか

推測で終わらせず、2つを突き合わせて確定させました。

**1. スクリーンショットのピクセル色を測る**

- エディタ背景: `#282C34`
- サイドバー: `#22252A`

**2. 拡張が同梱しているテーマのJSON定義を読む**

拡張のディレクトリ（`~/.vscode/extensions/` 配下）にテーマ定義のJSONが入っています。

```json
"colors": {
  "editor.background": "#282C34",
  "sideBar.background": "#22252A",
}
```

完全一致でした。これで「いま見えているのは、この拡張が持ち込んだテーマ」と断定できます。

配色の問題は「なんか変わった気がする」で終わりがちですが、**色は数値なので、突き合わせれば白黒つきます。**

## 結末

`"Default Dark Modern"` と明示的に書き直して解決しました。見慣れた表示に戻っています。

ちなみに、**Office Viewer 自体も結局オフにしました。** 普通の表示のほうが見やすかったので。

原因が分かったうえで戻す判断ができたのは、特定作業をやった副産物だと思います。
分からないまま「なんか変になった」で消していたら、拡張のせいにして終わっていました。実際には拡張は何も悪いことをしていません。
テーマの同梱は作者の親切機能で、ぶつかったのは自分の設定に残骸があったからです。

## 一段深い話——「壊れていないズレ」は長生きする

これを整理していて、引っかかったことがあります。

今回のズレは、**不具合として現れませんでした。**

- 設定に書いてある名前 → 存在しないテーマ
- 実際の表示 → デフォルトテーマ

食い違っているのに、デフォルトテーマは普通に見やすいので誰も困りません。困らないから、誰も気づかない。

**壊れていないズレほど長生きします。**

これは設定ファイル全般に言えそうだな、と思いました。実際、WordPressでも同じ形のものをよく見ます。
テーマやプラグインを削除しても、`wp_options` にレコードだけ残っている、というやつです。あれも普段は何も起きません。

何かを消したとき、**それを指していた名前は残る。** そして多くのシステムは、指し先が無いことを黙って許します。

設定ファイルの棚卸しをするなら、「書いてある設定が効いているか」まで見ないと意味がない、ということでもあります。
書いてあることと効いていることは別なので。

## まとめ

- VS Codeは、指定テーマが見つからないと**警告なくデフォルトで表示する**
- そのため「設定の名前」と「実際の配色」が長期間ズレていても気づけない
- 別の拡張が同名テーマを同梱していると、迷子の名前が突然実体化する
- 特定はピクセル色 vs テーマ定義JSONの突き合わせでできる。**色は数値なので白黒つく**
- **壊れていないズレは長生きする**。設定ファイル全般に言えそう
