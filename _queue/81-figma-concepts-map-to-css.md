Web制作で Figma は何年か触ってきました。
ただ、やっていたのは**デザイナーが作ったファイルを Dev Mode で読み取ること**がほとんどです。
自分で作ることはなくて、基本的な操作が分かっていませんでした。

今回、ポートフォリオのラフを自分で描く必要が出ました。
入門動画を探したところで、手が止まりました。
**1時間の動画を見る前に、用語だけ確認してみよう**と思ったからです。

結果として、動画は見ませんでした。用語を覚え直す必要がほとんどなかったからです。

## ほぼ全部、CSS に対応していた

| Figma | CSS / HTML でいうと |
|---|---|
| レイヤーパネル | **DOMツリーそのもの**。絵を並べているのではなく、入れ子を作っている |
| **Frame** | `<div>`。自分のサイズを持ち、はみ出しをクリップでき、子の配置ルールを持てる |
| **Group** | ただの選択の束ね。`<div>` ですらない（子に合わせてサイズが変わる） |
| **Auto Layout**（縦・横） | **flexbox**。方向・gap・padding・align、名前が違うだけ |
| **Auto Layout**（グリッド） | **CSS Grid**。2025年に3つ目のフローとして追加された |
| **Constraints** | 親をリサイズしたとき子がどう追従するか。`position: absolute` の上下左右固定に近い |
| Component / Instance | コンポーネントの定義と呼び出し |
| **Component Properties** | **props**。boolean / text / instance swap / variant の4種類がある |
| Variants | 同じコンポーネントの別バージョン（`sm` / `md`、`default` / `hover`） |
| **Variables** | **CSS変数**。モードを持てるのでライト/ダークの切り替えに対応する |
| Styles | 装飾のまとまり。どちらかというとクラスに近い |

最初に書きかけたときは「Variants = props」「Styles と Variables = CSS変数」と並べていました。
調べたら両方ずれていて、props に当たるのは Component Properties、CSS変数に当たるのは Variables のほうでした。
**Styles のほうは影や枠といった装飾をまとめて再利用する仕組み**で、役割が違います。

Auto Layout も、2025年の更新で守備範囲が広がりました。
縦・横に加えて**グリッドのフロー**が入り、2次元のレイアウトが組めます。
同じ更新で、子が入りきらないときの挙動が `space-between` に揃うなど、CSS 側に寄せる変更も入りました。
以前の挙動は Legacy として残っていて、2027年1月まで切り替えられます。

## 「デザイナーのファイルが読めない」の正体

読み取り側をやっていたとき、たまに構造が追えなくなるファイルがありました。あれは**Auto Layout の入れ子**でした。

flexbox の入れ子と同じです。`flex-direction: row` の中に `column` があって、その中にまた `row` がある。
CSS で書いてあれば読めるのに、パネルの数値として並ぶと追えなくなっていました。
**読めなくしていたのは入れ子の深さのほう**でした。

Frame と Group の違いも、ここで効きます。Group はサイズを持たないので、中身を動かすと外枠も動きます。
`<div>` のつもりで見ると挙動が合いません。**迷ったら Frame** にしておけば、CSS で考えている構造とズレなくなりました。

## ラフに必要だったのは4つだけ

実際にラフを描いてみたら、使った機能は4つでした。

- **フレーム**（`F`）
- **矩形**（`R`）
- **テキスト**（`T`）
- **整列**

Auto Layout もコンポーネントも使っていません。
ラフは「どこに何が何個あるか」を決める作業なので、再利用の仕組みが要りませんでした。

覚えたショートカットも少しです。

| キー | 何が起きるか |
|---|---|
| `⌘D` | 複製 |
| `⌥` + ドラッグ | 複製しながら移動 |
| `⇧1` / `⇧2` | 全体にズーム / 選択にズーム |

等間隔にカードを並べたいときは、**`⌥` + `Shift` でドラッグ複製してから `⌘D` を押します**。
直前の複製と同じ間隔で繰り返してくれるので、位置を計算せずに並びます。
これは知らないと手で揃えることになる操作でした。

入門動画は Auto Layout とコンポーネントの説明に時間の大半を使います。
どちらもラフでは使わないので、**作業そのものより動画のほうが長い**という状態でした。

## 列グリッドは CSS Grid そのものだった

もう1つ、そのまま対応していたのがレイアウトガイドです。

「列」を選んで、数を3・余白を64・間隔を16にすると、画面に縦線が引かれます。
この3つの数字は、そのままこれです。

```css
grid-template-columns: repeat(3, 1fr);
gap: 16px;
padding-inline: 64px;
```

数字を入れながら「これ書いたことがある」と思いました。
**デザインツール側の設定項目に、CSS で毎日書いているものが並んでいた**形です。

## 名前がついていただけだった

やってみて分かったのは、知らなかったのは概念ではなく**名前の対応**だったということでした。
DOM も flexbox も Grid も CSS変数も、コードの側では使ってきたものです。

未経験の道具に入るとき、**先に用語だけ自分の言葉に訳してみる**と、必要な学習量がはっきりします。
今回は訳し終わった時点で、動画を見る理由がなくなりました。
逆に、訳せない用語が多く残るなら、そこが本当に新しい概念のところです。

Dev Mode で読むだけだったころも、同じものを見ていたはずでした。
読む側と作る側で、見えているものが違っただけだったと思います。
