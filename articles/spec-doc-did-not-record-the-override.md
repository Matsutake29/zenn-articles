2作目のポートフォリオとして「Hubpin」（分散した発信を1か所に集めるハブサイト）を作りながら書いています。

- リポジトリ: https://github.com/Matsutake29/hubpin
- Next.js（App Router） + Supabase + Tailwind CSS
:::

自分で作った静的サイトを、Next.jsのアプリに作り直しています。

デザインの仕様書は自分で書いたものが残っていました。移植リストも作りました。
色とフォントを写して、あとはコンポーネントに割り直すだけ。**移すだけのはずでした。**

その移植リストを、現物のCSSが否定してきました。

## 明朝体を移そうとして、記憶が引っかかった

仕様書には見出しに明朝体を使うと書いてあります。移植リストにもそう書き写しました。

書き写した直後に、引っかかりました。このフォント、読みにくかったので途中で変えた気がする。
ただ、いつ変えたのか、どこを変えたのかが思い出せません。仕様書には明朝を使うとしか書いていない。

記憶違いかもしれないので、公開中のサイトをブラウザで開いてDevToolsを立ち上げました。

## 打ち消し線が残っていた

本文の要素を選んで Styles パネルを見たら、こうなっていました。

```
body { font-family: var(--font-jp); }            ← 打ち消し線
.p-hero__lead { font-family: var(--font-sys); }  ← 効いている
```

明朝を指定したあとで、本文だけシステムのゴシックに上書きし直していました。
実際に適用されていたのは `-apple-system, ..., "Hiragino Sans", "Noto Sans JP"` のほうです。

記憶は正しかった。**読みにくかったので変えていた。**

ここで効いたのがDevToolsの打ち消し線でした。
CSSファイルを grep しただけだと、両方の宣言が見つかって「どちらも書いてある」としか分かりません。
どちらが勝っているかは、ブラウザに計算させないと出てきません。

## その判断は、どこにも書かれていなかった

改めて自分の資料を確認しました。

- デザイン仕様書 → 明朝を指定した記述しかない
- 移植リスト → フォントの上書きに触れていない
- 開発メモ → 該当なし

**読みにくかったから変えた**という理由が、どのドキュメントにも残っていませんでした。
残っていたのは、打ち消し線というCSSの実行結果だけです。

同じ調子で仕様書と現物を突き合わせたら、別のズレも出てきました。
仕様書に載っている「Frontend Works（Coming Soon）」というカードが、実物では別の作品に置き換わっていました。
公開してから差し替えて、仕様書に書き戻していない。

## 仕様書には「決めたこと」しか書いていなかった

構造としては単純でした。

仕様書は着手前に書きます。そこに入るのは**決めたこと**です。
作り始めてから「やってみたら違ったので変えた」ものは、実装には反映されますが、仕様書には戻りません。

書き戻す習慣がなかった、という一言で終わる話ではあります。
ただ、書き戻さなかったことで消えるのは**判断の結果ではなく理由のほう**だと分かったのが、今回の収穫でした。

結果は実装に残ります。明朝からゴシックに変えたという事実は、CSSを読めば出てきます。
消えるのは「読みにくかった」という理由です。そして次に同じ判断をするときに必要なのは、理由のほうです。

## 仕様書だけを見ていたら、捨てた明朝を復活させていた

移植リストのとおりに作っていたら、一度やめた明朝体を新しいアプリに持ち込んでいました。
そして同じように読みにくくて、同じように直していたはずです。

同じ「読みにくい」を2回踏むことになる。

なので、移植の手順を少し変えました。仕様書を読んだあとに、**必ず公開中の現物をDevToolsで開く**。
仕様書に書いてある値と、実際に適用されている値を突き合わせてから、移植リストを確定させる。

自分で作って自分で運用していたサイトでも、1年経つとこうなっていました。
他人が作ったサイトを引き継ぐときは、もっと出てくるだろうと思います。

## 記録の側も少し変えた

理由が消えるほうが問題なので、今回から開発ログに「却下した案とその理由」を書くようにしています。

決定事項だけを書くと、あとから読んだときに**なぜ他の選択肢ではないのか**が分かりません。
自分の場合、分からないと同じ検討をもう一度やっていました。

実装は判断の結果しか残してくれません。理由は書き戻さないと消えます。
